# Hiveage MCP by usefulapi

Use [Hiveage](https://www.hiveage.com) from Claude, Cursor, or any MCP client — work with your clients, invoices, estimates and payments. Hosted, no local install: connect with your own Hiveage credentials.

**Live endpoint:** `https://hiveage.usefulapi.io/mcp` · **Homepage:** https://usefulapi.io/hiveage

## Connect

- **Claude** (claude.ai, Desktop): open **Customize → Connectors**, click **+ Add → Add custom connector**, and paste `https://hiveage.usefulapi.io/mcp`.
- **Claude Code:** `claude mcp add --transport http hiveage https://hiveage.usefulapi.io/mcp`, then run `/mcp` to log in.
- **VS Code:** [Add to VS Code](https://vscode.dev/redirect/mcp/install?name=hiveage&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fhiveage.usefulapi.io%2Fmcp%22%7D).
- **Cursor and other clients:** add the URL as a remote MCP server:

```json
{
  "mcpServers": {
    "hiveage": {
      "url": "https://hiveage.usefulapi.io/mcp"
    }
  }
}
```

Add only the URL. Do not add an `Authorization` header or an API key to the client config: the server signs you in with OAuth, and the login page asks for your Hiveage credentials.

Step-by-step setup, where to find your credentials, and FAQ: https://usefulapi.io/hiveage/

On first connect you'll enter your **Hiveage account subdomain and API key** (Hiveage Launchpad > Your Global Profile). They are validated, stored per-user, and scoped to you — no keys in config files.

## Tools

| Tool | Type | What it does |
|------|------|--------------|
| `hiveage_list_connections` | read | List connections |
| `hiveage_get_connection` | read | Get connection |
| `hiveage_list_connection_invoices` | read | List a connection's invoices |
| `hiveage_list_connection_estimates` | read | List a connection's estimates |
| `hiveage_list_connection_recurring_invoices` | read | List a connection's recurring invoices |
| `hiveage_list_contacts` | read | List contacts |
| `hiveage_get_contact` | read | Get contact |
| `hiveage_list_invoices` | read | List invoices |
| `hiveage_get_invoice` | read | Get invoice |
| `hiveage_list_estimates` | read | List estimates |
| `hiveage_get_estimate` | read | Get estimate |
| `hiveage_list_recurring_invoices` | read | List recurring invoices |
| `hiveage_get_recurring_invoice` | read | Get recurring invoice |
| `hiveage_list_recurring_invoice_invoices` | read | List invoices generated by a recurring invoice |
| `hiveage_list_payments` | read | List invoice payments |
| `hiveage_get_payment` | read | Get payment |
| `hiveage_list_categories` | read | List saved items, expense, task or trip categories |
| `hiveage_create_connection` | **write** | Create connection |
| `hiveage_create_contact` | **write** | Create contact |
| `hiveage_update_contact` | **write** | Update contact |
| `hiveage_create_invoice` | **write** | Create invoice |
| `hiveage_create_estimate` | **write** | Create estimate |
| `hiveage_record_payment` | **write** | Record invoice payment |
| `hiveage_mark_payment_realized` | **write** | Mark payment realized |
| `hiveage_create_saved_item` | **write** | Create saved item |
| `hiveage_send_invoice` | **write** | Send invoice by email |
| `hiveage_send_invoice_reminder` | **write** | Send invoice reminder by email |
| `hiveage_send_estimate` | **write** | Send estimate by email |
| `hiveage_usage_status` | meta | Usage status (free-tier meter) |
| `hiveage_request_feature` | meta | Request a missing feature |
| `hiveage_upgrade` | meta | Upgrade to Pro (unlimited*) |
| `hiveage_cancel_subscription` | meta | Cancel the Pro subscription |

`read` tools are read-only; `write` tools mutate data (clients should confirm them); `meta` tools report usage, manage your subscription or send a feature request.
